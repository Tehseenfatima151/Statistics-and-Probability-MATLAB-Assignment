# Statistics & Probability Theory – Assignment 01

## 📌 About the Project

This repository contains my **Statistics & Probability Theory Assignment 01**, completed as part of my university coursework.

The assignment focuses on implementing fundamental statistical concepts using **MATLAB**. It includes calculations, data analysis, frequency distributions, and graphical representations to understand how statistical methods work in practice.

## 🎯 Objectives

- Understand fundamental concepts of Statistics and Probability.
- Perform statistical calculations using MATLAB.
- Organize and analyze data using frequency distributions.
- Calculate measures of central tendency.
- Represent statistical data using graphs and charts.
- Develop practical problem-solving skills through MATLAB programming.

## 🛠️ Tools & Technologies

- **Programming Language:** MATLAB
- **Platform:** MATLAB Online
- **File Format:** MATLAB Script (`.m`)

## 📂 Assignment Contents

The assignment is divided into seven questions, with each question implemented in a separate MATLAB script.

| File | Topic |
|---|---|
| `Q1.m` | Variables and Scales of Measurement |
| `Q2.m` | Sampling Techniques |
| `Q3.m` | Frequency Distributions |
| `Q4.m` | Cumulative Frequency and Ogive |
| `Q5.m` | Frequency Curves and Data Presentation |
| `Q6.m` | Stem-and-Leaf Plot and Measures of Central Tendency |
| `Q7.m` | Arithmetic Mean, Weighted Mean, Median, and Mode |

## 🚀 How to Run

1. Clone or download this repository.
2. Open MATLAB or visit [MATLAB Online](https://matlab.mathworks.com/).
3. Upload the `.m` files or open the downloaded scripts.
4. Run each script individually.
5. Review the command-window output and generated graphs.
